# Виртуальный казино-бот для Telegram

Полностью игровой бот: тенге не имеет реальной ценности, вывести её нельзя.
Реализовано на `aiogram 3`, всё хранится в SQLite (`casino.db`, создаётся автоматически).

Полный список команд с описанием всегда доступен по кнопке **/** рядом с полем ввода —
меню разное для личных чатов, групп и админов/владельца (см. ниже).

## Игры

- **/coinflip [ставка] [orel/reshka]** — орёл/решка, x2
- **/dice [ставка] [more/less]** — кости 1-6, "больше 3.5" (4-6) или "меньше" (1-3), x2
- **/slots [ставка]** — слот-машина с разными множителями (до x25 за три 💎)
- **/roulette [ставка] [вариант]** — рулетка 0-36. Варианты: red/black/green (x2 / x14),
  even/odd (x2), low/high — 1-18/19-36 (x2), либо конкретное число (x36)
- **/rps [ставка] [rock/paper/scissors]** — камень-ножницы-бумага против бота, x2
- **/wheel [ставка]** — колесо фортуны со случайным множителем (x0 - x10)
- **/keno [ставка] [числа]** — кено: выбери 1-4 числа от 1 до 20 через запятую
  (`/keno 100 3,7,15`), бот тянет 8 чисел, оплата по числу совпадений
- **/mines [ставка] [мин]** — поле 5x5, открывай клетки без мин, множитель растёт с каждой
  открытой клеткой, забирай выигрыш кнопкой в любой момент
- **/blackjack [ставка]** (или `/bj`) — блэкджек (21) против дилера: «Ещё карту» / «Хватит»,
  натуральный блэкджек платит x2.5, обычная победа — x2
- **/hl [ставка] [higher/lower]** (или `/higherlower`) — угадай, будет вторая карта больше
  или меньше первой, x2
- **/crash [ставка]** — "трейдинг"-график: множитель растёт, нужно нажать «Забрать»
  до того, как график рухнет
- **/lottery [ставка]** — лотерея с общим банком: покупаешь билет, шанс выиграть весь банк
  пропорционален размеру твоего билета относительно всех билетов. Раунд стартует с первым
  билетом в чате и завершается автоматически через настроенное время (по умолчанию 2 минуты)
- **/duel [ставка]** *(только в группах)* — вызов другого игрока на дуэль ответом на его
  сообщение; монетка решает, кто забирает обе ставки

## Экономика

- **/balance** — баланс
- **/daily** — ежедневный бонус. Растёт со стриком: чем больше дней подряд заходишь,
  тем больше бонус (до потолка, настраивается владельцем). Пропуск более 48 часов сбрасывает серию
- **/pay [user_id] [сумма]** (или `/transfer`) — перевести тенге другому игроку.
  Ответом на его сообщение (`/pay 100`) или напрямую по ID (`/pay 8721768505 100`).
  **В группах** уведомление о переводе остаётся в группе и никогда не улетает получателю в ЛС —
  приватность соблюдена
- **/mystats** — своя статистика: сыграно игр, выиграно/проиграно всего, серия бонусов
- **/top** — глобальная таблица лидеров
- **/roll** — просто бросить кубик без ставки, для развлечения

## Групповые команды

- **/duel [ставка]** — см. выше
- **/grouptop** — таблица лидеров именно этого чата (а не всех пользователей бота)
- **/groupgive [сумма]** *(админ)* — начислить тенге всем известным игрокам этого чата разом —
  удобно для активаций/рекламы в конкретной группе

Групповые команды работают только в групповых и супергрупповых чатах. Добавь бота в группу
как обычного участника — отдельные права администратора в самой группе не нужны.

## Владелец и админка

Две роли:

**Владелец** — задаётся один раз через переменную окружения `OWNER_ID` (твой Telegram ID,
узнать через `/myid`). Управляет админами и экономикой прямо в чате бота, без захода на хостинг:
```
OWNER_ID=8721768505
```
- `/addadmin [user_id]` — назначить админа (у него сразу появится расширенное меню команд)
- `/removeadmin [user_id]` — снять админа
- `/admins` — список владельца и всех админов
- `/setminbet [сумма]` / `/setmaxbet [сумма]` — лимиты ставок для всех игр
- `/setdailybonus [сумма]` — базовый размер ежедневного бонуса (до прибавки за стрик)
- `/setstartbalance [сумма]` — стартовый баланс для новых игроков (на уже существующих не влияет)

**Админы** — назначаются владельцем через `/addadmin`, либо через переменную `ADMIN_IDS`
(список ID через запятую — оставлено для обратной совместимости):
```
ADMIN_IDS=123456789,987654321
```

Команды, доступные админам (и владельцу):

- `/give [user_id] [сумма]` — начислить/забрать (отрицательное число) тенге игроку
- `/setbalance [user_id] [сумма]` — жёстко выставить баланс (в отличие от `/give`, который
  прибавляет/вычитает)
- `/userinfo [user_id]` — полная карточка игрока (баланс, игры, победы/поражения, стрик)
- `/stats` — общая статистика бота (игроков, суммарная тенге в экономике, всего игр)
- `/groupgive [сумма]` — массовое начисление всем игрокам конкретной группы
- `/broadcast [текст]` — рассылка (реклама/объявление) всем игрокам бота
- `/giveaway [приз] [макс_участников] [время]` — розыгрыш с кнопкой «Участвовать».
  Лимит участников — число, или `0` для безлимита (розыгрыш завершится по таймеру).
  Время — секунды или с суффиксом: `30s`, `10m`, `2h`, `1d`.
  Пример: `/giveaway 1000 0 2h` — приз 1000, без лимита участников, розыгрыш через 2 часа.
  Если лимит указан и заполняется раньше времени — розыгрыш завершается сразу
- `/endgiveaway` — досрочно завершить текущий розыгрыш в этом чате
- `/economy` — посмотреть все текущие настройки экономики одним сообщением

## Меню команд (кнопка "/")

Бот сам настраивает список команд, который всплывает при нажатии `/`:
- В **личных чатах** — все игровые и экономические команды
- В **группах** — то же самое плюс `/duel` и `/grouptop`
- У **админов и владельца** в личном чате с ботом — дополнительно появляются
  админские (и владельческие) команды. Меню обновляется автоматически при
  `/addadmin`/`/removeadmin`, а также подтягивается заново при первом `/start`.

## Запуск

1. Получи токен бота у [@BotFather](https://t.me/BotFather).
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Задай токен через переменную окружения и запусти:
   ```bash
   export BOT_TOKEN="твой_токен_сюда"
   export OWNER_ID="твой_telegram_id"
   python bot.py
   ```
   (На Windows: `set BOT_TOKEN=...` / `set OWNER_ID=...`)

## Структура проекта

- `bot.py` — хендлеры команд, меню команд, запуск бота
- `games.py` — логика игр (генерация исходов, крэш-график, карты, кено)
- `database.py` — SQLite: баланс, топ игроков, настройки экономики, статистика

## Что можно добавить дальше

## Важно

Это развлекательный бот с виртуальной валютой без возможности вывода реальных денег.
Если планируешь публиковать бота широко, стоит явно указать в описании, что игра
ознакомительная/игровая, без денежных ставок.
