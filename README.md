# Виртуальный казино-бот для Telegram

Полностью игровой бот: фишки не имеют реальной ценности, вывести их нельзя.
Реализовано на `aiogram 3`, баланс хранится в SQLite (`casino.db`, создаётся автоматически).

## Игры

- **/coinflip [ставка] [orel/reshka]** — орёл/решка, x2
- **/dice [ставка] [more/less]** — кости 1-6, ставка на "больше 3.5" (4-6) или "меньше" (1-3), x2
- **/slots [ставка]** — слот-машина с разными множителями (до x25 за три 💎)
- **/roulette [ставка] [red/black/green/число]** — рулетка 0-36, цвет x2 (зеро x14), число x36
- **/rps [ставка] [rock/paper/scissors]** — камень-ножницы-бумага против бота, x2
- **/wheel [ставка]** — колесо фортуны со случайным множителем (x0 - x10)
- **/mines [ставка] [мин]** — поле 5x5, открывай клетки без мин, множитель растёт с каждой
  открытой клеткой, забирай выигрыш кнопкой в любой момент
- **/crash [ставка]** — "трейдинг"-график: множитель растёт, нужно нажать «Забрать»
  до того, как график рухнет. Чем дольше ждёшь — тем выше множитель, но и риск краха растёт.
- **/balance** — баланс
- **/daily** — ежедневный бонус (+500 фишек раз в 24 часа)
- **/top** — таблица лидеров
- **/myid** — узнать свой Telegram ID (нужен, чтобы стать админом)

## Групповые команды

- **/duel [ставка]** — вызвать другого участника чата на дуэль: ответь (reply) на его сообщение
  командой `/duel 100`. Соперник видит кнопки «Принять»/«Отклонить»; если примет — монетка
  определяет победителя, он забирает обе ставки.
- **/grouptop** — таблица лидеров именно этого чата (а не всех пользователей бота).

Работают только в групповых и супергрупповых чатах — в личке бот ответит, что команда доступна
только в группе. Добавь бота в группу как обычно; отдельных прав администратора в самой группе
ему для этого не нужно.

## Владелец и админка

Есть две роли:

**Владелец** — задаётся один раз через переменную окружения `OWNER_ID` (твой Telegram ID,
узнать через `/myid`). Только владелец может назначать и снимать админов прямо в чате бота,
без захода на хостинг:
```
OWNER_ID=8721768505
```
- `/addadmin [user_id]` — назначить админа
- `/removeadmin [user_id]` — снять админа
- `/admins` — список владельца и всех админов

**Админы** — либо назначены владельцем через `/addadmin`, либо перечислены в переменной
`ADMIN_IDS` (список ID через запятую, как раньше — оставлено для обратной совместимости):
```
ADMIN_IDS=123456789,987654321
```

Команды, доступные админам (и владельцу):

- `/give [user_id] [сумма]` — начислить (или забрать, если сумма отрицательная) фишки игроку.
  Игрок должен был хотя бы раз запустить `/start`, чтобы попасть в базу.
- `/broadcast [текст]` — разослать сообщение (рекламу/объявление) всем игрокам бота.
- `/giveaway [приз] [секунд]` — запустить розыгрыш с кнопкой «Участвовать»;
  по истечении времени бот сам выбирает случайного победителя и начисляет приз.

## Запуск

1. Получи токен бота у [@BotFather](https://t.me/BotFather).
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Задай токен через переменную окружения и запусти:
   ```bash
   export BOT_TOKEN="твой_токен_сюда"
   python bot.py
   ```
   (На Windows: `set BOT_TOKEN=твой_токен_сюда`)

## Структура проекта

- `bot.py` — хендлеры команд, запуск бота
- `games.py` — логика игр (генерация исходов, крэш-график)
- `database.py` — работа с SQLite (баланс, топ игроков)

## Что можно добавить дальше

- Дуэли/PvP-ставки между игроками
- Настройка стартового баланса и лимитов ставок
- Более сложный "рынок" с несколькими виртуальными активами и графиками цен для полноценной имитации трейдинга

## Важно

Это развлекательный бот с виртуальной валютой без возможности вывода реальных денег.
Если планируешь публиковать бота широко, стоит явно указать в описании, что игра
ознакомительная/игровая, без денежных ставок.
